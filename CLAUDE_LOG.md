## 2026-10-13 — Modernize dependencies, remove dead code, add agent docs

**Goal:** bump Node and dependencies, remove anything unused, document the repo for future agent sessions. Breaking the contact form was declared acceptable.

**Dependencies / tooling**
- `next` `latest` (locked at 12.1.5 in the old `yarn.lock`) → `^16.4.0`; `react`/`react-dom` `17.0.2` → `^19.3.0`; `@sendgrid/mail` `^7.6.2` → `^8.1.6`.
- Added `"engines": { "node": "24.x" }` (also tells Vercel which Node to use).
- Switched yarn → npm: deleted `yarn.lock`, added `package-lock.json` (yarn wasn't installed; npm ships with Node).
- Removed `nanoid` dependency.
- `AGENTS.md` added: generated by `next dev` (Next 16 agent rules), imported from `CLAUDE.md`.

**Code changes for the upgrade**
- `next/image`: `width="70px"`/`"32px"` strings → numbers (Header, MobileHeader, Footer); gallery `objectFit='cover'` (removed prop) → `style={{ maxWidth: '100%', height: 'auto' }}`.
- `next/link` now renders `<a>`, which made nav items blue + underlined → added global `a { color: inherit; text-decoration: none; }` in `Layout`.

**Removed as unused**
- `src/pages/old-index.js` (unlinked placeholder page at `/old-index`) and its image `clutch-e-bag-fashion-tech-made-in-italy-home-pic.jpg`. The `-min.jpg` version stays (it is the `og:image`).
- `src/components/UnderConstruction/` (never imported) and its image `...-pochette-page-under-construction-big.jpg`.
- `public/assets/iconmonstr-shape-14.svg`, `iconmonstr-shopping-bag-17.svg` (never referenced).
- Vimeo `player.js` `<Script>` in `gallery.js` (the plain iframe embed doesn't need it).
- `nanoid` keys in `philosophy.js` / `CustomSection.js` → stable keys (random keys also forced remounts on every render).
- `TODO.md` (2022 task list referencing files that never existed: `product.js`, `Menu/mobileMenu.js`). Still in git history.

**Verified**
- `npm run build` passes with no warnings; routes: `/`, `/philosophy`, `/gallery`, `/contact`, `/404`, `/api/sendgrid`.
- `npm start` + headless Chrome screenshots of every page at desktop (1440px) and home at mobile (390px): layout, header, footer, carousel, cookie banner render as expected.
- `POST /api/sendgrid` responds (401 Unauthorized without a real `SENDGRID_API_KEY`) — the route works, email delivery not tested.

**Bug fixes (follow-up request, same session)**
- `Head/head.js`: `og:url` was just the page slug (`productionURL + pageURL === 'home' ? ...` parsed as a comparison). Now the full URL, e.g. `https://www.clutchebag.com/philosophy`; home is `https://www.clutchebag.com/`.
- `Header/header.js`: resize listener was added/removed with two different anonymous functions, so it was never removed. Both now use the same `setResponsiveness` reference.
- `api/sendgrid.js`: email body was HTML with raw user input interpolated (HTML injection into the inbox). Switched to a plain-text email (`text` instead of `html`) and removed the `console.log` of the request body (leaked personal data into server logs).
